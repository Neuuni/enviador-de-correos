# Sistema de Envío Masivo de Correos

Sistema para enviar correos de bienvenida personalizados de forma masiva.

## Características

- ✅ Envío masivo de correos personalizados
- ✅ Soporte para archivos Excel, CSV y TXT
- ✅ Plantillas predefinidas
- ✅ Vista previa en tiempo real
- ✅ Progreso de envío
- ✅ Manejo de errores
